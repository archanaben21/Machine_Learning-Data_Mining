# Read Me

## Task 1: Predicting Online Shopping Behaviour - A Classification Analysis

### Overview:
This folder contains code and resources for predicting online shopping behavior using a classification analysis. The task is based on the "Online Shoppers Purchasing Intention Dataset," encompassing 12,330 online sessions.

### Files: ObesityDataSet_raw_and_data_sinthetic.csv

1. **KNN.py:** 
   - **Purpose:** Main script for the classification analysis.
   - **Usage:** Execute this script to perform the online shopping behavior prediction and for Classification.
   
2. **DecisionTree.py**
   - **Purpose:** Auxiliary functions to enhance code modularity.
   - **Usage:** for Classification

## Task 2: Unravelling Obesity - Clustering Insights from Eating Habits and Physical Condition

### Overview:
This folder contains code and resources for clustering insights related to obesity levels based on eating habits and physical condition. The task uses records from Mexico, Peru, and Colombia.

### Files: online_shoppers_intention.csv

1. **KNNClustering.py:**
   - **Purpose:** Jupyter Notebook for clustering insights from the dataset.
   - **Usage:** Explore relationships between eating habits and physical condition.

2. **DBSCANClustering.py:**
   - **Purpose:** Jupyter Notebook for clustering insights from the dataset.
   - **Usage:** Explore relationships between eating habits and physical condition.
